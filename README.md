# On Web Data Mining

*Repozitář obsahuje soubor individuálních úloh vypracovaných v rámci předmětu Web Data Mining na FIT ČVUT.
Jednotlivé úlohy pokrývají různé oblasti získávání, zpracování a analýzy webových dat.*

## Individuální úlohy

1. [Webový crawler](01/index.adoc)
   - Extrakce informací o náramkových hodinkách pomocí frameworku **Scrapy**.
   - Získávání dat přímo z obsahu webových stránek bez využití strojově čitelných metadat, 
   jako jsou Open Graph nebo JSON-LD.

2. [Text Mining a NLP](02/index.adoc)
   - Experimenty s analýzou sentimentu, rozpoznáváním pojmenovaných entit (NER) a klasifikací entit.
   - Zero-shot klasifikace a automatická sumarizace.

3. [Analýza sociálních sítí](03/index.adoc)
   - Experimenty s různými metrikami centrality a metodami detekce komunit.
   - Reprezentace uzlů pomocí vektorových embeddingů grafů.

4. [Analýza návštěvnosti webu](04/index.adoc)
   - Analýza uživatelských kliknutí a návazností návštěv jednotlivých stránek 
   s cílem odvozovat asociační pravidla.
   - Segmentace uživatelů na základě navštívených stránek a času návštěv 
   pomocí shlukování.

5. [Informační vyhledávání](05/index.adoc)
   - Experimenty s různými reprezentacemi textu pro vyhledávání: binární reprezentace,
   TF, TF-IDF a husté vektorové reprezentace pomocí transformerů.
   - Porovnání přístupů k reprezentaci a vyhledávání textových dokumentů.

6. [Doporučovací systémy](06/index.adoc)
   - Experimenty s doporučováním filmů pomocí obsahového filtrování (content-based), 
   kolaborativního filtrování a hybridních metod.
   - Implementace doporučovacích modelů s využitím TensorFlow.
