== 5. Indexing + Document Retrieval

Для виконання завдання було використано попередньо спрацьовану версію cranfield датесету (https://courses.fit.cvut.cz/NI-DDW/hw/05/files/cranfield.zip[скачати]).
Вона містить:

* `/d`:
    - тиксти з 1400 доступних документів
    - lower case, пунктуація видалена, речення розділені крапкою
* `/q`
    - тексти 225 запитів у форматі як документи
* `/r`
    - списки релевантних документів для кожного з `q`

Після начитання документів не виконується подальше спрацювання по типу лематизації. Це веде до створення
використання багато розмірних векторів (к-ть унікальних токенів приблизно 20 тис), проте такі
дані чітко покажуть недоліки репрезентації (spasre, збільшення середньої відстані між подібними даними).

=== Тестовані репрезентації та метрики
В даній роботі будуть порівняно наступні резпрезентації:

* Binary representation
* Term Frequency
* TF-IDF
* Dense ("sentence-transformers/all-MiniLM-L6-v2")

Далі виконується рангування документів окремо відносно cosine similarity (1 - cos) та euclidean distance (покаже проблеми з ненормованістю векторів).

Оцінюватись дані підходи будуть за використання:

* Precision@K
* Recall@K
* F1@K
* MRR

Причому для значень використовуються наступні:

* [1, 3, 5, 10, 15, 25, 35, 50]

=== Sparse репрезентації
Для імплементації використовується бібліотека `sklearn`, кінцева к-ть властивостей (příznaků) `20524`.
З даної к-ті вже очікується що хороших результатів простим порівнянням векторів недосягти (напр. при IR в Lucene та подібних
для запитів би використовувались напр. топ 25 найпопулярніших токенів запиту чи подібно), наступні результати ж це підтверджують

==== Оцінка sparse репрезентацій
В загальному в усіх варіантах прослідковується низький рівень як precision так і recall, з покращенням
при "ускладненні" методу репрезентації. Найгірших результатів досягає TF з використання euclidean. Це спричинено
тим, що при так великій к-ті просторів та небінарними значеннями компонент, загальні дистанції між векторами
документів стають стабільно вискоими, незалишаючи жодних близьких (подібних векторів).

Найкращих результатів очікувано досягає tf-idf репрезентація з cosine мірою. Досягається це кращим
ігноруванням невиважених документів (невиважених подібностей) та нормалізацією величин векторів (дільник формули cos).

В усіх випадках з cosine подібністю, MRR приблизно дорівнює 0.5 (досягаючи піку в 0.67) що означає, що перший
зі знайдених релевантних документів рідко мав найкращу ранкінг.

Отже підсумовуючи, використання tf-idf на так погано спрацьованих даних може давати прийнятні результати з використанням
k = 50, досягаючи приблизно 0.6 recall. Інші методи недають recall навіть близький 0.5.
